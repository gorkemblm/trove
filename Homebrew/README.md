# Homebrew tap

Casks for [Trove](https://github.com/gorkemblm/trove), an encrypted clipboard history for macOS.

```sh
brew install --cask gorkemblm/tap/trove
```

Trove updates itself; `brew upgrade --cask --greedy trove` updates it through Homebrew instead.
The cask is generated by `make cask` in the Trove repository for each release.
